# lolilend_auto_collect_bonus
Небольшая программа созданная для полу-автоматизации получения монет на игровом проекте lolilend

(скрипт написан при помощи ИИ)

### как пользоатвься? ->
1. Заходим на [сайт lolilend](https://loliland.ru/ru/login) и авторизовываемся -> нажимаем ПКМ (Правая кнопка мыши) по пустому месту на сайте и нажимаем "Просмотреть кож элемена" (комбинация клавишь CTRL+SHIFT+C) -> открываем вкладку "Network" -> выполняем любое действие на сайте (должны появиться покеты в списке) -> открываем любой пакет из списка -> заходим во вкладку "Cookies" -> находим в таблице вкладки "access_id" и "access_token"
2. открываем скрипт через любой текстовый редактор -> копируем значения из "access_id" и "access_token", и вставляем в соотвествующие строки скрипта
>     "access-id" = "########-####-####-####-############"
>     "access-token" = "################################################################"
3. Сохранить файл и потавить на автозагрузку
### Некоторые уточнения:
* Скрипт будет работать до перезахода на сайт. После перезахода нужно обновить "access_id" и "access_token"
* При включении пк на небольшое время будет открываться консоль PowerShell, это нормально при работе скрипта
