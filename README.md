# lolilend_auto_collect_bonus
Небольшая программа созданная для полу-автоматизации получения монет на игровом проекте lolilend

(скрипт написан при помощи ИИ)

### как пользоатвься? ->
1. Заходим на [сайт lolilend](https://loliland.ru/ru/login) и авторизовываемся -> нажимаем ПКМ (Правая кнопка мыши) по пустому месту на сайте и нажимаем "Просмотреть код элемена" (комбинация клавишь CTRL+SHIFT+C) -> открываем вкладку "Network" -> выполняем любое действие на сайте (должны появиться пакеты в списке) -> открываем любой пакет из списка -> заходим во вкладку "Cookies" -> находим в таблице вкладку "access_token"
2. открываем скрипт -> создаётся файл token.txt -> копируем значения "access_token" и вставляем в token.txt
3. создаём ярлык .exe файла и добавляем его в автозагрузку
### Некоторые уточнения:
* Скрипт будет работать до перезахода на сайт. После перезахода нужно обновить "access_token"
* файл token.txt и log.txt должны находиться с исполнительным файлом в одной папке
